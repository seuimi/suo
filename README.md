# suo

Paper 26.3 서버에서 플레이어끼리 아이템을 맞교환하는 거래 플러그인입니다.

명령어는 `/suo <닉네임>` 하나뿐입니다. 거래를 걸고 싶은 사람이 상대 닉네임을 입력하면 상자 GUI가 열리고, 상대는 채팅의 버튼을 눌러 수락하거나 거절합니다.

## 서버

- Paper **26.3**
- Java **25**

## 빌드

```bash
./gradlew build
```

완성된 파일은 `build/libs/suo-1.0.0.jar` 입니다. 서버의 `plugins` 폴더에 넣고 리로드하거나 서버를 다시 시작하면 됩니다.

## 거래 순서

1. `/suo <닉네임>` 을 입력하면 **보낼 물건** 상자(2줄)가 열립니다.
   - 첫 줄 9칸에 보낼 아이템을 올립니다.
   - 둘째 줄은 `회색 회색 회색 확인 회색 취소 회색 회색 회색` 입니다.
   - **확인**(초록 유리판)을 누르면 올린 아이템이 내 인벤토리에서 빠지고 상대에게 요청이 갑니다.
   - **취소**(빨간 유리판)를 누르면 아이템이 돌아오고, 나에게 `!! 거래가 취소되었습니다 !!` 가 빨간색 굵은 글씨로 표시됩니다.
2. 상대 채팅에 두 줄이 표시됩니다.

   ```
   (요청한 사람) 님이 거래를 요청했습니다.
   [ 수락 ] [ 거절 ]
   ```

   수락은 초록색, 거절은 빨간색입니다.
3. 상대가 **수락**을 누르면 **받을 물건 및 보낼 물건** 상자(4줄)가 열립니다.
   - 1줄: 요청한 사람이 보낸 물건
   - 2줄: 회색 유리판
   - 3줄: 상대가 돌려줄 물건을 올리는 칸
   - 4줄: 같은 확인/취소 버튼
   - 여기서 취소하면 양쪽 아이템이 각자 인벤토리로 돌아가고, 둘 다 빨간색 굵은 취소 메시지를 받습니다.
4. 상대가 **확인**을 누르면 요청한 사람에게 두 줄이 갑니다.

   ```
   (거래 받은 사람) 님과의 거래 내역을 확인해주세요.
   [ 확인 ]
   ```

   확인 글씨는 금색입니다.
5. 그 글을 누르면 **거래 최종 확인** 상자(4줄)가 열립니다.
   - 1줄: 내가 보낸 물건
   - 2줄: 회색 유리판
   - 3줄: 상대가 보낸 물건
   - 4줄: 같은 확인/취소 버튼
   - **확인**을 누르면 둘 다 `!! 거래가 승인되었습니다 !!` 를 초록색 굵은 글씨로 받고, 아이템이 서로 교환됩니다.
   - **취소**를 누르면 양쪽 아이템이 원래 주인에게 돌아가고, 둘 다 빨간색 굵은 취소 메시지를 받습니다.

거절을 눌러도 거래는 취소됩니다. 요청한 사람의 아이템은 인벤토리로 돌아가고 양쪽 모두 취소 메시지를 받습니다.

창을 그냥 닫거나, 죽거나, 접속을 끊어도 올려 둔 아이템은 주인에게 돌아갑니다. 인벤토리가 가득 차 있으면 남은 아이템은 발밑에 떨어집니다.

채팅 버튼을 누른 뒤 3분 동안 다음 응답이 없으면 거래는 자동으로 취소됩니다.
